# demos
## Règles pour chaque nouvelle démo

- **Intro animée obligatoire (~2 s)** à l'entrée du site : fond aux couleurs du commerce, petite animation SVG liée au commerce, nom qui apparaît lettre par lettre, « Touchez pour entrer », joue une seule fois par visite (sessionStorage). Voir n'importe quelle démo existante (`<div id="intro">`).
- Bandeau « Maquette proposée par Brixel Pro » en haut de la page.
- Pas de photos ni de logo copiés du site du commerce.
- Dossier nommé `nom-du-commerce-ville/` → en ligne sur `brixelpro.com/demos/nom-du-commerce-ville/`.
